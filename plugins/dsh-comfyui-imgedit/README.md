# dsh-comfyui-imgedit

图片编辑 / 多图合成：Qwen-Image 2.1，把 1–10 张参考图按指令合成一张新画面。

## 面板

侧栏「图片编辑」。素材区「＋ 上传 / 从 output 选… / ↻」，卡片显示缩略图、编号与文件名。

## 两个必须知道的行为

1. **输出比例跟随第 1 张**（工作流里 latent 尺寸由第一张参考图决定）。想要竖构图就把竖图放第一位。
2. **指令用「第 N 张」指代**，不要用 `<Picture N>`——这个模型不认标签，靠图片顺序理解。

## AI 润化

- 会先把参考图（最多 6 张）发给会话模型看，再改写指令
- 改写后检查「第 N 张」是否覆盖全部图片，漏了会在按钮旁提示
- 模型不支持读图时自动降级为纯文字改写

## 工具

| 工具 | 说明 |
| --- | --- |
| `image_edit` | `images` 数组 1–10 张 + `prompt`；`background: true` 异步 |
| `image_edit_status` | 查任务状态 |

## 工作流

`workflows/qwen_image_edit.api.json`（19 节点，含可选 `TextGenerate` 增强）。参考图映射：第 1 张 → `470`，第 2 张 → `475`，第 3–10 张动态建 `900+`。
