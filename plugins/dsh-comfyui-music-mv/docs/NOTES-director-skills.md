# 学习笔记：AI 导演 Skill 生态里能直接搬的东西

记于 2026-11-18。来源两个：

- `github.com/kangarooking/director-skills`（7 个 Skill，MIT）——读完了 `cinematic-asset-prompts` 与 `emotion-performance-director` 两份 SKILL.md
- `shortdramaskills.com`（115 个短剧/漫剧 skill 的目录，手工核对，2026-11-16）——读了目录、分类页与 `llms.txt`，并对照读了榜上最重的 `manju-laoli-skill`（★2.1k，1 总控 + 10 子技能 + 48 份规则库 + C1~C41 机检）

这份笔记只记**能落到我们代码里**的东西。结论先行：

> 这套生态真正值钱的不是提示词文采，是**工序**：资产先锁、锁完才分镜、分镜过机检才投喂、投喂稿还要过一道闸门。
> 我们缺的不是"更好的形容词"，是**把每一步的产物变成可被判定的字段**。

## 1. 资产：四类，各有硬约束，不许混用

来源：`cinematic-asset-prompts/SKILL.md`

| 类型 | 硬约束 | 我们现在的状态 |
|---|---|---|
| 角色定妆 | 全身、自然站立、正面、**无动作**、纯色背景 | 有，但没禁"动作/侧身" |
| 场景空镜 | **绝对没有人**、全景广角、电影光 | 有（`plates`），提示词没写"全景广角" |
| 道具 | 正交或纯侧视、中性灰底、孤立物体 | **完全没有** |
| 风格定调 | 全资产共用同一句关键词 | 刚加 `styleAnchor`（v2 第 1 步） |

三条禁令（对我最有用的部分）：

1. 角色提示词里**不许写环境全景**——写了模型就会把定妆拍成场景照；
2. 场景提示词里**不许出现人**——哪怕"远处一个人影"，空镜就废了；
3. 道具提示词里**不许有无关人物或场景**——否则道具的形制会被场景带偏。

> 落到我们：`renderHero` / `renderPlate` / 未来的 `renderProp` 应该是**三个互斥的模板函数**，而不是同一个 `buildT2iPrompt` 加不同参数。现在正是后者。

## 2. 提示词七段式

来源同上。

```
① 风格定调句（全片同一句，逐字复用）
② 主体声明（这是谁/这是什么，一句话说死）
③ 结构分解（整体 → 局部：先躯干，再手，再配饰）
④ 配色系统（主色 / 辅色 / 点缀色，用色名不用形容词）
⑤ 旧化痕迹（磨损、灰尘、水渍——"看起来很新"是最假的地方）
⑥ 负面约束（写进正文，不靠采样参数）
⑦ 英文固定后缀（类型词 + 视角 + 背景 + 灯光 + 画质 + 画幅）
```

我们的 `composeFramePrompt` 顺序是「角色 → 场景 → 动作 → 摄影 → 情绪 → 服装 → 基调」，**结构对了一半**：

- ✅ 已有主体声明、动作、摄影、后缀
- ❌ 缺"旧化痕迹"（这条解释了我们为什么总觉得画面"太干净、像样片"）
- ❌ 负面约束散落在各处，没有集中成一段
- ⚠️ 风格句刚加，还没进资产（只进了帧）

## 3. 表演：五通道 + 三拍 + 修剪

来源：`emotion-performance-director/SKILL.md`

公式：**潜台词 → 2–4 个可观察信号 → 时序 → 余韵**

- 五通道：**目光 / 呼吸 / 脸 / 身体 / 声音**，每格只挑 2–4 个；
- 三拍：**说话前 / 说话中 / 说话后**；"余韵"是后果，不是额外动作；
- 修剪原则：**删掉一个动作，情绪还读得出，就删掉**；
- 默认自然主义：微反应、延迟、不完整的手势、台词后的残留；
- 三条禁令：**不许默认加眼泪**、**不许直视镜头**、**不许用"很悲伤"代替行为**；
- 低能量情绪动作更少；**静止是有效的表演选择**。

> 已落地：`performance` 支持 `{before, during, after, channels}`，`inferChannels` 兜底，机检 `perf-channels`（≤4）与 `no-auto-tears`。
> 还差：**"不许直视镜头"没有机检**（现在只在提示词里说）；**通道去重**（同一片里 21 格全是 body+gaze 也算单调）。

## 4. 五道前置锁：没指定就停下问

来源：`manju-laoli-skill`（README「五道前置锁 + I 画风锁」）

| 锁 | 选项 | 为什么重要 |
|---|---|---|
| 素材来源 | 原创 / 改编 / 对标爆款 / 热点 | 决定要不要先出《对标情报卡》 |
| 模型 | 二选一（它家是 Seedance 2.5/2.0） | **语法契约分流**，选错全篇重写 |
| 画幅 | 16:9 / 9:16 / 21:9 | 与模型同时锁 |
| 交付形态 | 看板 / md / both | 强制锁，未指定=停下 |
| 段缝衔接 | 末帧承接 / 换机位硬切 / 空镜 / 技巧转场 | 多段拼接的成败就在这 |
| 画风锁 | 候选卡里选 | 选定即冻结 |

关键态度：**"任何一道未指定，必须停下询问并把选项摆出来，禁止默认跳过、禁止替用户推断。"**

> 我们现在是全部给默认值（时长 120、静帧 8MP、16:9…）。对 MV 这种小项目，默认值是对的；但**"段缝衔接"这一条值得单独拎出来**——我们只有 `tailLink` 一个开关，等价于"全片末帧承接"，而生态里明确说四种方式要按段落选。

## 5. 素材形态 M0 / M1 / M2

来源同上。

- **M0 纯提示词**：只有字，没有图；
- **M1 编号占位**：提示词里用 `@角色1` 这样的编号占位，图还没出；
- **M2 已入库**：图已生成并登记进台账。

规则：**每次交付首行声明形态**，且投喂层要校验"编号一致性 + 素材形态一致性"。

> 这条正好解释了我们踩过的坑：在 M1 状态下（定妆还没出）就去渲染，模型只能瞎猜，于是"狗头人身"。我们现在靠 `jobMatchesPlan` 判归属，方向对，但**没有显式的形态声明**，用户看不出这是"占位"还是"已锁"。

## 6. 单实例道具锁

来源：`sd-asset-engine`（"道具单实例锁"）+ 台账 `PRP`

一个道具在全片只能有一个实例、一套形制；跨镜复用同一张资产图。

> 这正是我们最疼的地方：铃铛在第 7、19、21 镜是三只不同的铃铛。**道具资产卡是 v2 第 2 步，优先级最高。**

## 7. 站位声明四要素 + 轴线锁

来源：`sd-asset-engine` / `sd-storyboard-engine`

- 站位声明四要素：**谁 / 在哪 / 朝哪 / 和谁的关系**（一行写完，每镜必写）；
- **180° 轴线**：同一场戏里人物在画面左右的位置不能翻，否则观众会晕；
- 位移链：这一镜从哪走到哪（不是"他在走动"，是"从左二格走到窗口"）。

> 我们的 `composition` 只管构图类型（ots/two/single），**没有左右位置**。所以反打镜里两个人经常"跳边"。加一个 `side`（left/right）字段 + 反打时互换，是低成本高收益。

## 8. 禁令失效三改法（这条最反常识）

来源：`manju-laoli-skill`「禁令失效三改法」

> **模型对否定不敏感，对词根敏感。**

所以「不要出现手」这三个字里，"手"仍然被激活了。三改法：

1. **高关联概念换词**：不要写"不要出现血"，写"雨把地面冲成干净的灰"；
2. **主体优先句式**：先说"画面里只有狗的四条腿"，而不是"不要出现人"；
3. **触发器移除**：删掉会引出它的那个词（写了"手"就 AI 一定画手）。

【强制禁止项】只装**真正的负面清单**（画幅比例、水印、文字），不要拿它当主要控制手段。

> 我们的提示词里"不要…"极多：`不要文字、不要水印`（这条对）、`不要出现手/不要出现人的脸`（这条危险）。**下一步应该把人物降级的写法从否定式改成主体式**："画面主体只有一只狗的四条腿与尾巴，地面占画面下三分之一"。

## 9. 机检 C1~C41 + 投喂层闸门

来源：`manju-laoli-skill`（`validate_prompt.py` C1~C26，增量 C27~C41，共 104 条子检查码；`gate_check.py` 投喂层闸门）

两类检查要分开：

- **稿件级机检**：结构、字段、语法、禁令；
- **投喂层闸门**：编号一致性（第 3 镜引用的资产编号在清单里存在吗）、素材形态一致性（声明 M2 但台账里没有图）。

还有一条工程经验值得抄：他们的 P14 补丁把 `gate_check.py` 与 `validate_prompt.py` 的**重复判据合并成单一实现**，"出稿质检从三跑变一跑"。

> 我们 31 项体检全在一个 `lintPlan` 里，暂时没有重复问题；但**我们的机检只看剧本，不看提示词**。下一个该加的闸门是"第 N 镜引用的地点/道具资产是否真的存在"。（v2 第 4 步的资产确认关就是这个。）

## 10. 12 节拍情绪曲线

来源：`short-drama-director`（全片张力 0~10 量化 + 折线图）

> 我们有 `arc`（起承转合）但它是文字；**张力是一条 0–10 的数值曲线**，可以画成折线、可以和镜头时长叠加看。
> 对我们最有用的一点：**时长应该跟着张力走**（张力高的地方切得密）。我们已经按 chorus/verse 调权重，但没有真正的"张力"字段。

## 11. 动作强度分档 R1/R2/R3

`R1 写实克制 / R2 商业高燃（默认） / R3 玄幻大招`，先定档再写分镜。

> 我们的分镜没有"强度"概念，导致 21 镜全是中等强度，看起来平。加一个 `intensity: 1|2|3` 字段，机检要求"全片至少一镜 R1、一镜 R3"，比现在的"景别不三连"更有用。

## 14. 三条要记住的原则

1. **能判定的才写进规则。** "要高级""要有电影感"永远判不出来；"风格锚 8–60 字""通道 ≤4 个""每个 prop 前中后各一次"可以。
2. **否定句基本无效。** 想让人看见狗，就写狗；想让人看不见人，写"画面里只有狗"而不是"没有人"。
3. **拉满分之后一定要读产物。** 100 分的稿子曾经出现"双手插兜，旧夹克还在手里"——评分项全过，句子在描述第三只手。机检挡不住荒谬，只有读能。
