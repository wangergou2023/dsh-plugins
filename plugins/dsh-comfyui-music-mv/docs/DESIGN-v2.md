## 一、这两份材料真正教了什么

**1. 资产不是「定妆图」，是四类，各自有硬约束。**

| 类型 | 硬约束 | 我们现在的状态 |
|---|---|---|
| 角色定妆 | 全身、自然站立、正面、**无动作**、纯色背景 | ✅ 有（但没强制"无动作/正面"） |
| 场景空镜 | **绝对没有人**、全景广角、电影光 | ⚠️ 刚做（plates），提示词里没有强制"全景广角" |
| 道具/载具 | 正交或纯侧视、中性灰底、可当资产参考 | ❌ **完全没有** |
| 风格定调 | 全资产共用同一句关键词 | ❌ 只有松散的 `plan.look` |

三类提示词**互不混用**：角色提示词里不许写环境全景，场景提示词里不许出现人，道具提示词里不许有无关人物或场景。

**2. 提示词是七段式骨架，不是一堆形容词。**

风格定调句 → 主体声明 → 结构分解（整体→局部）→ 配色系统 → 旧化痕迹 → 负面约束（写进正文，不靠参数）→ 英文固定后缀（类型词 + 视角 + 背景 + 灯光 + 画质 + 画幅）。

我们的 `composeFramePrompt` 现在是「角色 → 场景 → 动作 → 摄影 → 情绪 → 服装 → 基调」，顺序是对的，但**缺少风格锚句的逐字复用**，也没有把负面约束集中成一段。

**3. 表演是「潜台词 → 2–4 个可观察信号 → 三拍时序 → 余韵」。**

- 信号只从五个通道里挑：目光、呼吸、脸、身体、声音；**2–4 个，不许多**。
- 三拍：**说话前 / 说话中 / 说话后**。余韵是"后果"，不是额外的戏剧动作。
- 修剪原则：**删掉一个动作后情绪仍然读得出来，就删掉它**。
- 默认自然主义：克制的微反应、延迟、不完整的手势、台词后的残留反应。
- 明确禁止的偷懒：一看情绪就加眼泪；让角色直视镜头；用"很悲伤"这类标签代替行为。

我们的 `performance` 现在是「先…→ 停在哪 → 最后…」，方向对，但**没有通道数量约束、没有三拍与台词的绑定、没有修剪规则**，模型经常一格里塞五个信号。

**4. 门控流水线：上一步通过才走下一步。**

生态里成熟的做法是分阶段卡关：剧本 → 资产 → 分镜 → 首帧 → 视频，每一关有人（或机检）确认。我们目前是「一键到底」，中间只有静帧一处停。

**5. 一致性靠四种机制，不是靠提示词祈祷。**

尾帧承接（我们有 tailLink）、延长、锁定资产卡（我们有参考图，但只有角色和地点）、插入关键帧。其中**道具资产卡是我们最缺的一环**——铃铛、牛奶瓶、小指骨在不同帧里形状都不太一样。

**6. 规则化质检（机检）是普遍做法。**

短剧生态里几个成熟项目都带「机检」：把可判定的规则写成脚本，不靠模型自评。我们的 28 项体检就是这个思路，方向对，要继续加。

## 二、差距清单（按影响排序）

| # | 差距 | 后果（实拍验证过的） |
|---|---|---|
| 1 | 没有道具资产卡 | 同一个铃铛在第 7、19、21 镜是三只不同的铃铛 |
| 2 | 没有逐字复用的风格锚句 | 同一部片里胶片感/调色在漂 |
| 3 | 表演没有通道上限与三拍约束 | 一格塞五个信号，观众读不出主次 |
| 4 | 资产阶段没有"确认关" | 定妆/空镜一旦出错，21 格静帧全部报废 |
| 5 | 机检缺少"表演通道"和"风格锚"两项 | 体检 100 分也可能台词外全是形容词 |
| 6 | 没有失败模式库 | 同一个坑（狗耳少年、白骨印花裙）反复踩，靠人记 |

## 三、新架构：六层

```
L0 主题        theme + 时长 + 画幅
L1 剧本        plan + lint（28 项 → 32 项）
L2 资产        角色定妆 / 地点空镜 / 道具资产 / 风格锚  ← 新增：道具、风格锚、确认关
L3 分镜        每镜 form / composition / performance / 参考图清单
L4 静帧        参考图生图（角色 + 地点 + 道具）
L5 视频        首帧 + 末帧接龙 + 对口型
L6 成片        拼接 / 转场 / 调色 / 导演本
```

**L2 是本轮重做的核心。** 资产层产出四样东西，全部进 `job`，全部可单独重出：

1. `heroes[]`：角色（原形 / 人形 / 过渡）——已有
2. `plates[]`：地点空镜——已有（本轮补"全景广角 / 无人"硬约束）
3. `props[]`：**道具资产卡（新）**——正交视图、中性灰底、孤立物体，每个 prop 一张
4. `styleAnchor`：**风格锚句（新）**——一句话，逐字进所有资产与所有镜头提示词

**L3 的表演字段改成三拍协议：**

```
performance: {
  before: "说话前：喉结动了一下，视线落在对方手里的铃铛上",
  during: "说话时：声音压得很低，尾音没抬起来，右手把铃铛往身后藏了半寸",
  after:  "说完后：没有立刻走，等了两秒才转身",
  channels: ["gaze", "voice", "body"]   // 2–4 个，机检
}
```

兼容旧格式：字符串会被当成 `during`，`before/after` 由返修补。

**机检新增四项（29–32）：**

- `props-asset`：每个 prop 都有资产卡（出图后才判；未出图时跳过）
- `style-anchor`：风格锚句存在，且长度 8–60 字、不含"很/非常/比较"这类空词
- `perf-channels`：每镜 `channels` 2–4 个，且不全相同
- `no-auto-tears`：没有台词写"哭"，却在 performance 里出现"泪"（除非同一镜 `cry: true`）

## 五、验收标准（这份设计算不算做到了）

- [ ] 一部 12 镜的片，四个道具在每一格里的形状一致（人眼抽查 ≥3 格）
- [ ] 21 格静帧的主色/颗粒/对比在同一档（并排看不出两套调色）
- [x] 每镜 `channels` 2–4，且没有一格同时出现泪/喊/抖三个高强信号（31 项机检已含 `perf-channels` / `no-auto-tears`）
- [x] 资产阶段能停下来，改完定妆再继续，不用重跑静帧（`phase: 'assets'`）
- [ ] 体检 ≥30 项，且 100 分的片人眼读一遍不出现"第三只手"级别的荒谬（当前 31 项）
